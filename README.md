# 🌍 Executive Tours & Travel — Official Website

> Premium Travel & Tour Agency based in Bhubaneswar, Odisha. Tailored domestic and international holidays, luxury fleet rentals, Tempo Travellers, passport & visa documentation assistance.

---

## 🚀 Features
- **120 FPS High-Performance Engine**: Frame-rate independent momentum inertia smooth scrolling and seamless page transitions.
- **Full Static & Responsive Suite**: 28 handcrafted pages covering Tour Packages, About Us, Fleet & Services, Travel Journal Guides, Photo Galleries, and Contact Inquiries.
- **Node.js Production Server (`server.js`)**: Real-time Gzip/Deflate compression, in-memory mtime-aware caching, security headers (`nosniff`, `SAMEORIGIN`), and immutable asset streaming.
- **Interactive Micro-Interactions**: Filter tabs, 3-card photo switcher, mobile menu drawer, and animated CTA actions.

---

## 🛠️ Quick Start

### 1. Clone & Run
```bash
git clone https://github.com/Kr-Kaushik/Executive-Tours-Travel.git
cd Executive-Tours-Travel
node server.js
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
